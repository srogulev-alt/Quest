# Тест по постановлениям Пленумов ВС РФ и ВАС РФ: клиент-серверная версия

Сервер на Python и Flask, данные в SQLite. Участники проходят тест в браузере по адресу сервера, ничего устанавливать им не нужно. Правильные ответы хранятся и проверяются **только на сервере**: до завершения теста браузер их не получает.

В банке 502 вопроса (4 варианта ответа) по 25 блокам, четыре направления входа: микс, гражданская, административная, банкротная коллегия.

## Что нужно

- Компьютер или сервер с **Python 3.9+** (Windows, Linux, macOS).
- Библиотеки **Flask** и **waitress** (ставятся скриптом запуска).
- Участникам: любой современный браузер и доступ к серверу по сети.

## Запуск

- **Windows:** дважды щёлкните `start.bat`.
- **Linux/macOS:** `./start.sh`.

Скрипт создаст окружение, установит Flask и waitress и запустит сервер на порту **8080**.

- Тест для участников: `http://адрес-сервера:8080/`
- Панель администратора: `http://адрес-сервера:8080/admin`

При первом открытии `/admin` задайте пароль (не короче 6 символов). Либо задайте его заранее переменной `TEST_ADMIN_PASSWORD`.

Если на сервере нет интернета: на компьютере с интернетом выполните `pip download -r requirements.txt -d wheels`, скопируйте папку `wheels` рядом с `app.py`, и скрипт запуска установит библиотеки оттуда.

### Настройки запуска (переменные окружения)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | 8080 | порт |
| `HOST` | 0.0.0.0 | на каком адресе слушать (`127.0.0.1` — только с этого компьютера) |
| `TEST_DATA_DIR` | `data/` рядом с `app.py` | где хранить базу и ключ сессий |
| `TEST_ADMIN_PASSWORD` | — | начальный пароль администратора |
| `TRUST_PROXY` | — | `1`, если сервер стоит за обратным прокси (nginx, Caddy): IP участников берётся из `X-Forwarded-For` |

## Как это работает

1. Участник выбирает направление и вводит **фамилию и имя** (пароля нет).
2. Сервер случайно выбирает вопросы из блоков этого направления, перемешивает варианты и запоминает правильный ответ у себя. Браузеру отправляются только текст и варианты.
3. Таймер ведёт сервер: по истечении времени ответы не принимаются, попытка закрывается сама (даже если участник закрыл вкладку), неотвеченные вопросы считаются неверными. Если страницу обновить или закрыть, тест можно продолжить.
4. Ответы проверяются на сервере, результат сохраняется в базу сразу. Протоколы никуда пересылать не нужно.
5. После теста показывается либо разбор (ответы и пояснения), либо только баллы и номера ошибок, как задано в настройках.

## Панель администратора

- **Вопросы:** поиск, фильтр по блоку, добавление, правка, удаление, выбор верного ответа, экспорт и импорт JSON (объединить или заменить).
- **Коллегии и блоки:** какие блоки входят в гражданскую, административную и банкротную коллегии, переименование блоков, новые блоки.
- **Настройки:** открыть или закрыть тест, название, число вопросов, время, лимит попыток на фамилию, режим результата (разбор или только баллы), какие варианты входа показывать, какие блоки включать, смена пароля.
- **Результаты:** журнал попыток, подробный разбор каждой, фильтры, выгрузка в CSV (открывается в Excel), вопросы с наибольшим числом ошибок.

Настройки действуют для новых попыток; уже начатые попытки идут по прежним условиям. Правка вопроса не меняет вопросы в уже начатых попытках.

## Администрирование сервера

- **Резервная копия** (можно при работающем сервере): `python backup.py` создаёт `data/backup-ДАТА.db`. Делайте её регулярно и храните вне сервера.
- **Сброс пароля администратора:** `venv/bin/python reset_admin.py НОВЫЙ_ПАРОЛЬ` (на Windows `venv\Scripts\python reset_admin.py НОВЫЙ_ПАРОЛЬ`). После сброса или смены пароля все открытые сеансы администратора закрываются.
- **Данные** лежат в папке `data/` (`test.db` и `secret.key`). Для переноса на другой сервер скопируйте эту папку.
- **Автозапуск:** на Windows — через планировщик заданий или службу (например, NSSM), на Linux — через systemd, запустив `/путь/к/venv/bin/python /путь/к/app.py`.
- **Нагрузка:** сервер работает через waitress (8 потоков); этого хватает на десятки и сотни одновременных участников. Если waitress не установлен, используется встроенный сервер Flask.

## Безопасность и ограничения

- **Вход по фамилии и имени без пароля** означает, что любой может пройти тест под чужой фамилией. Для контроля задайте «Попыток на одну фамилию» и ограничьте доступ к серверу сетью организации.
- Сервер работает по **HTTP**. Для внешнего доступа и шифрования поставьте перед ним обратный прокси с HTTPS (nginx, Caddy и т.п.) и задайте `TRUST_PROXY=1`.
- Вход администратора: пароль хранится в виде хеша, после 5 неверных попыток вход блокируется на минуту, изменяющие запросы защищены от подделки с чужих сайтов.
- В базе хранятся фамилия и имя участников, время и IP-адрес попытки: учитывайте требования о защите персональных данных.
- Банк вопросов перенесён из офлайн-версии без изменений. Полной сверки всех 502 вопросов с действующими кодексами и последней практикой ВС РФ не проводилось: проверены и исправлены самые уязвимые места по АПК РФ (изменения 2024–2026 годов). Перед официальным использованием проведите полную проверку.
